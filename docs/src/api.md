# API reference

The three functions are independent: supply your own density vector or graph to [`tomato`](@ref) when the built-in choices do not fit your data. See [parameters and interpretation](parameters.md) for self-neighbour counting, graph truncation, finite-death recording and equal-density plateaus. The default `τ=Inf` permits all eligible merges.
